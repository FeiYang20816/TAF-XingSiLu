# 行思录 · 网页交互预览

把经历沉淀为经验，把想法留给未来。

本目录是行思录的独立界面与流程原型，不是 APK。原生 Android 应用位于 [android/](../android/)，网页相关文件统一位于 `web/`。

## 打开预览

最简单：双击 `index.html`，使用新版 Edge 或 Chrome 打开即可。所有图标、样式、代码都在本地，无外部字体、CDN 或第三方服务，不需要联网。

推荐：在本目录（`XingSiLu/web/`）打开终端执行：

```powershell
npm start
```

再打开 <http://127.0.0.1:4173>。无需 `npm install`。关闭终端或按 `Ctrl+C` 即可停止服务。

端口占用时可执行 `$env:PORT=4174; npm start`。服务只监听本机，并仅提供三个网页文件，不开放仓库其他文件或备份。

## 可以体验什么

- 经验：一句话总结即可保存，详情自由补充。首次点击“保存经验”，以后自动保存；离开编辑页时也会尝试保存有效内容。
- 想法：只写正文，不需要标题；输入后约 450 毫秒自动保存，不创建空白记录。
- 搜索：分别匹配当前模块的正文、总结及标签；支持标签筛选、最近更新 / 最近创建排序、置顶。
- 编辑：桌面并排浏览和编辑；手机宽度下分列表与编辑页面，底部导航为“经验 / 想法”。
- 辅助信息：标签、相关日期默认折叠；均可不填写。
- 删除：先确认，再进入回收站；可恢复或二次确认永久删除。
- 导出：全部经验、全部想法或单条记录导出为 UTF-8 Markdown，保留正文段落。
- 备份：JSON 保存全部记录、标签、时间、置顶、回收站状态与外观设置。恢复会校验格式并合并记录：同 ID 同内容跳过；同 ID 不同内容生成副本，不覆盖现有内容。恢复不会替换当前外观设置。
- 外观：浅色、深色、跟随系统。
- 记录时间：设置中可选择显示或隐藏列表及编辑页的记录时间，默认隐藏。创建与修改时间仍正常保存，可在折叠的“更多信息”中查看，导出和备份不受影响。

首次打开提供 4 条示例经验、3 条示例想法，编辑区有“示例记录”标识。示例可以正常编辑、删除，不会在删完后重新生成。

## 数据与使用边界

数据使用浏览器 `localStorage` 保存，键名为 `xingsilu.preview.v1`。本页没有网络请求，也不会上传记录。

**浏览器预览不等于 Android 的私有数据库。** 清理浏览器数据、换浏览器、换端口，或在直接打开文件和本地服务之间切换，都可能看到不同的记录。建议固定一种打开方式，重要内容及时导出 JSON 备份。浏览器限制本地存储、配额不足或数据格式异常时会显示错误，不会用示例覆盖已有数据。

原生 Android 版本已使用 Kotlin、Jetpack Compose、Room / SQLite 和系统文件选择器实现持久化及系统交互，详见 [Android 说明](../android/README.md)。本原型不包含账号、云同步、AI、提醒、打卡或统计面板。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面、对话框及本地 SVG 图标 |
| `styles.css` | 暖白 / 绿色主题、深色模式、手机适配 |
| `app.js` | 记录、搜索、保存、导出和备份逻辑 |
| `server.mjs` | 可选的零依赖本地预览服务 |
| `package.json` | 启动及语法检查命令 |

```powershell
npm run check
```

项目使用原生 HTML / CSS / JavaScript，无构建步骤、无第三方依赖，可作为后续设计迭代的独立原型目录。
